# Agent Memory

이 파일은 에이전트가 사용자에 대해 학습한 내용을 기록하는 장기 메모리다.
(선호, 반복되는 피드백, 역할 정의, 도구 사용에 필요한 정보 등)

## User

- 송환혁. AI Agent 기술 트렌드를 매일 추적한다(업무·학습·투자 참고용).
- 주 관심 소스: GeekNews, AWS 기술 블로그(AI/ML, Agentic AI).

## Preferences

- 한국어로 작성하고 기술 용어는 원어를 병기한다. 간결·사실 중심 톤.
- 브리핑은 "핵심 요약 3줄 + 항목별(제목 / 2~3줄 요약 / 링크 / 주목 포인트)" 구조를 선호한다.
- 투자 매수/매도 권유는 하지 않는다. 기술 트렌드 정보만 제공한다.
- API 키·웹훅 URL 등 자격증명은 파일에 저장하지 않는다.

## Project: 일일 AI Agent 브리핑

- 목표: 매일 08:00 KST 에 수집 → 정제 → 브리핑 초안 → `/briefings/YYYY-MM-DD.md` 아카이빙.
- 1단계(현재): 수집 → 초안 품질 검증. 2단계: 발송 채널 연결(Slack/메일) 후 스케줄링.
- 절차는 `ai-agent-daily-briefing` 스킬을 따른다.

## Notes

- GeekNews RSS 에는 코멘트 수가 없다. robots.txt 상 AI 학습 봇은 차단 → 일 1회 저빈도 RSS 만 사용.
- AWS Blog 는 웹 검색보다 RSS 가 안정적이다.
- 일시적 사건(서비스 장애 등)은 트렌드 가치가 낮아 제외한다.
