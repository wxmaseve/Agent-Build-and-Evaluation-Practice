# 브리핑 규칙 & 자기 점검 체크리스트

## 근거
- [ ] 모든 항목의 링크가 `fetch_feeds.py` 결과(또는 사용자가 준 자료)에 실제로 있는 URL 인가
- [ ] 요약의 수치·고유명사·발표 내용이 수집된 제목/요약에 있는가 (없으면 쓰지 않는다)
- [ ] 같은 URL·같은 사건이 두 번 나오지 않는가

## 관련성
- [ ] 각 항목이 AI Agent(에이전트 프레임워크·도구 호출·멀티에이전트·에이전트 런타임/플랫폼·
      코딩 에이전트·MCP/A2A 등 프로토콜·에이전트 평가/관측)와 직접 관련 있는가
- [ ] 일반 LLM/모델 출시·인물 가십·일시적 장애처럼 트렌드 가치가 낮은 글은 제외했는가
- [ ] 애매한 글을 넣었다면 "판단 보류·제외 메모"에 근거를 적었는가

## 형식
- [ ] 상단 핵심 요약 3줄
- [ ] 항목마다 제목 / 2~3줄 요약 / 링크 / 주목 포인트
- [ ] 한국어, 기술 용어 원어 병기(예: 에이전트 런타임(Agent Runtime))

## 안전
- [ ] 투자 매수/매도/보유 권유, 주가 전망 표현이 없는가
- [ ] API 키·토큰·웹훅 URL 을 파일이나 답변에 쓰지 않았는가
- [ ] 발송을 요청받았는데 채널 도구가 없으면, 보냈다고 말하지 않고 아카이빙만 한 뒤 설정 방법을 안내했는가
